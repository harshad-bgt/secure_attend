# Color Palette

The SecureAttend AI color palette is designed to be modern, trustworthy, and accessible. It uses a high-contrast foundation with vibrant accents for a premium SaaS feel.

## 1. Brand Colors
- **Primary Brand**: `#0052CC` (Deep Trust Blue)
  - Used for primary buttons, active states, and brand moments.
- **Secondary Brand**: `#00B8D9` (Cyan Accent)
  - Used for micro-animations, secondary indicators, and gradient meshes.

## 2. Backgrounds & Surfaces
### Light Theme
- **Background**: `#F4F5F7` (Light Grayish Blue)
- **Surface**: `#FFFFFF` (Pure White)
- **Elevated Surface**: `#FFFFFF` (With Level 2 Shadow)

### Dark Theme
- **Background**: `#091E42` (Deep Navy)
- **Surface**: `#172B4D` (Dark Blue-Gray)
- **Elevated Surface**: `#253858` (Lighter Blue-Gray)

## 3. Text & Content
### Light Theme
- **Primary Text**: `#172B4D` (Almost Black)
- **Secondary Text**: `#5E6C84` (Slate Gray)
- **Disabled Text**: `#97A0AF`

### Dark Theme
- **Primary Text**: `#FFFFFF`
- **Secondary Text**: `#B3BAC5`
- **Disabled Text**: `#7A869A`

## 4. Semantic Colors
- **Success**: `#36B37E` (Emerald Green) - Attendance marked, enrollment successful.
- **Warning**: `#FFAB00` (Amber) - QR expiring soon, missing permissions.
- **Error/Destructive**: `#FF5630` (Crimson) - Liveness failed, session end confirmation.
- **Information**: `#0065FF` (Bright Blue) - System notifications.
