# Design System

The SecureAttend AI Design System ensures visual consistency across the React Admin Panel and Flutter Application.

## Corner Radius (Border Radius)
- **Small**: 4px (Checkboxes, small inputs)
- **Medium**: 8px (Buttons, standard inputs)
- **Large**: 16px (Cards, dialogs, bottom sheets)
- **Full**: 9999px (Pills, circular avatars)

## Elevation (Shadows)
- **Level 1**: Subtle shadow for standard cards.
- **Level 2**: Slightly pronounced shadow for hover states.
- **Level 3**: Deep shadow for dropdowns and floating action buttons.
- **Level 4**: Highest elevation for critical dialogs.

## Spacing (Padding/Margin)
An 8-point grid system is used.
- `xs`: 4px
- `sm`: 8px
- `md`: 16px
- `lg`: 24px
- `xl`: 32px
- `xxl`: 48px

## Animation Durations
- **Fast**: 150ms (Hover effects, ripples)
- **Normal**: 300ms (Page transitions, dialog popups)
- **Slow**: 500ms (Complex layout shifts)
