# SecureAttend: Project Report & Documentation

## 1. Project Overview
SecureAttend is an advanced, two-factor attendance tracking system designed to eliminate proxy attendance. It combines cutting-edge Facial Recognition with dynamic, time-sensitive QR Codes to ensure that a student is both who they claim to be, and physically present in the classroom.

---

## 2. Technology Stack

### Backend API
*   **Framework:** FastAPI (Python)
*   **Database:** SQLite managed via SQLAlchemy ORM
*   **Facial Recognition:** OpenCV & DeepFace (for embedding generation and comparison)
*   **Security:** Passlib (Argon2 hashing) & PyJWT (Access, Refresh, and Proof Tokens)

### Admin Panel (Frontend)
*   **Framework:** React 18 (Bootstrapped with Vite)
*   **Styling:** TailwindCSS
*   **State & Data Fetching:** React Query (`@tanstack/react-query`)
*   **Icons & Utilities:** Lucide React, `qrcode.react` (for dynamic QR rendering)

### Mobile Application (Student App)
*   **Framework:** Flutter (Dart)
*   **Camera Integration:** `camera` (for Face capture) & `mobile_scanner` (for QR scanning)
*   **State Management:** Provider
*   **Networking:** `http` package for RESTful communication

---

## 3. Core Features

### Role-Based Access Control (RBAC)
*   Strict segmentation between Admins, Faculty, and Students using encrypted JWTs.
*   Comprehensive Audit Logging for security-critical actions (logins, enrollments, token generation).

### Dual-Factor Attendance Flow
1.  **Identity Verification (Face):** The student opens the app, and the camera captures their face. The backend compares the live capture against their enrolled database embedding. If matched, a temporary 60-second `face_proof_token` is issued.
2.  **Location Verification (QR):** The student immediately scans the live QR code projected by the faculty in the classroom. The QR code rotates and expires every 60 seconds to prevent photo-sharing.

### Native Face Enrollment
*   Students can self-enroll their facial data securely from their own smartphone dashboard.
*   Admins maintain the ability to manually upload student photos for enrollment via the web panel.

### Live Session Dashboard
*   Faculty can view a live counter and list of students as they successfully mark attendance in real-time.

## 4. How to Run the Project

This system requires three separate environments to be running simultaneously:

### Step A: Start the Backend (FastAPI)
1. Open a terminal and navigate to the API directory:
   ```bash
   cd e:\DEV\SecureAttend\backend\api
   ```
2. Activate the Python virtual environment:
   ```bash
   .\venv\Scripts\activate
   ```
3. Start the server (binds to all interfaces so the mobile phone can reach it):
   ```bash
   uvicorn main:app --host 0.0.0.0 --port 8000
   ```

### Step B: Start the Admin Web Panel (React)
1. Open a second terminal and navigate to the admin directory:
   ```bash
   cd e:\DEV\SecureAttend\backend\admin
   ```
2. Start the Vite development server (exposing it to the local network):
   ```bash
   npm run dev -- --host
   ```
3. Access the dashboard in your browser via `http://localhost:5173`

### Step C: Run/Build the Mobile Application (Flutter)
1. Open a third terminal and navigate to the Flutter project:
   ```bash
   cd e:\DEV\SecureAttend\apk_build
   ```
2. To run directly on a connected device via USB debugging:
   ```bash
   flutter run
   ```
3. To compile a standalone production APK (found in `build\app\outputs\flutter-apk\`):
   ```bash
   flutter build apk
   ```
